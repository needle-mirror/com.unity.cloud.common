# Unity Cloud Application Namespace

Applications built with Unity Cloud require an application namespace to enable custom URI scheme association with the OS in Deep Linking and login operations.

## Create an application namespace

By default, all application have the **com.unity.cloud** namespace.
To set up the application namespace manually, follow these steps:

1. Open your application project in the Unity Editor.
2. Go to **Edit > Project Settings > Unity Cloud > App Information**.
3. Edit the **App Namespace** input field.
