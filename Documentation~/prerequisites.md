# Prerequisites

Before you start using the Unity Cloud Common package, make sure you meet the following prerequisites.

## System requirements

A valid [Unity ID account](https://id.unity.com/) to generate an identifier for your application

## Compatibility

The Unity Cloud Common package is compatible with Unity version 2022.3 and all Unity Cloud packages.

## Supported platforms

* Windows Standalone
* Android
* macOS 
* iOS: Requires an Xcode project build and a valid development build certificate to achieve binding for the custom URI scheme at the OS level.
